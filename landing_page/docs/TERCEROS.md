# Componentes distribuidos

| Componente | Versión o fecha | Licencia y archivo |
| --- | --- | --- |
| Leaflet | 1.9.4 | BSD-2-Clause, `web/vendor/LEAFLET-LICENSE.txt` |
| jsPDF | 4.2.1 | MIT, `web/vendor/JSPDF-LICENSE.txt` |
| DejaVu Sans, fuente embebida para el PDF | Fuente del sistema, derivada de Bitstream Vera | Condiciones completas en `web/vendor/DEJAVU-LICENSE.txt` |
| Vías de OpenStreetMap | Extracto del 28/10/2026 | ODbL 1.0 y atribución; ver `CARTOGRAFIA.md` |

Las bibliotecas están incluidas para ejecutar el demo sin instalar dependencias JavaScript. No se distribuye cartografía de Google; su API se carga solo al configurar una clave. El GeoJSON de calles se distribuye como archivo editable, separado del código y de los datos ficticios de reportes.
